# DuLingua - Language Learning Android App

LinguaSpeak is an Android-based language learning application designed to improve vocabulary, pronunciation, speaking, and multilingual communication using speech and translation technologies.

The app integrates speech recognition, text-to-speech, pronunciation testing, and multilingual translation to create an interactive language learning experience.

---

## Features

### Vocabulary Learning
- Learn and save new vocabulary words
- Categorized word lists
- Meaning and pronunciation support

### Pronunciation System
- Built-in speaker functionality
- Listen to correct pronunciation
- Compare pronunciation accuracy

### Pronunciation Test
- Speech-based pronunciation evaluation
- Real-time feedback using speech recognition

### Speech-to-Text
- Convert spoken language into text
- Supports multiple languages

### Text-to-Speech
- Reads text aloud naturally
- Helpful for pronunciation practice

### Multi-language Translation
- Translate text between several languages
- Easy language switching interface
